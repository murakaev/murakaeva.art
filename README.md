## About

A minimalist artist portfolio focused on the work itself.  
No frameworks – pure HTML, CSS, and JavaScript.
 
## Stack
 
- **Vanilla JS** — ES modules, no frameworks
- **CSS** — BEM, custom properties, modular architecture
- **Fonts** — Lora + JetBrains Mono

## Structure
 
```
├── css/
│   ├── variables.css     # design tokens
│   ├── base.css          # reset, animations
│   ├── navbar.css
│   ├── hero.css          # name ticker
│   ├── gallery.css       # masonry grid
│   ├── lightbox.css
│   ├── about.css
│   ├── contacts.css
│   ├── footer.css
│   └── responsive.css    # iPad 11/13, iPhone Pro/Pro Max, Safari
├── js/
│   ├── main.js           # init, lightbox, reveal animations
│   ├── gallery.js        # gallery render, IntersectionObserver
│   └── ticker.js         # marquee ticker
└── index.html
```
